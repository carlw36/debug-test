# Java Debugging Demo

A small Java shopping-cart program for practicing debugging. It includes products, a cart, checkout calculations, discounts, tax, and inventory updates.

The sample contains intentional logic bugs. Use it to practice tracing program flow, checking calculations, and verifying that state changes match expectations.

## Requirements

- Java Development Kit (JDK) installed
- A terminal or Java IDE

## Run the program

Save the source as `DebugDemo.java`, then run:

```bash
javac DebugDemo.java
java DebugDemo
